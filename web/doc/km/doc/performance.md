# ប្រសិទ្ធភាព

`fkv_bench`សាកល្បង សរសេរ អាន និងស្កេនការផ្ទុកនៅលើចន្លោះគន្លឹះថេរ។

```bash
cargo run --release -p fkv_bench -- \
  --workload write-read --rows 20000 --batch-size 100
```

សូចនាករ​រួម​បញ្ចូល​ទាំង​ការ​បញ្ជូន​បន្ត ភាព​យឺតយ៉ាវ​នៅ​ដំណាក់កាល​នីមួយៗ និង RSS កំពូល។ ចេញផ្សាយលំហូរការងារចេញផ្សាយ x86_64 /
`fkv_bench`ប្រព័ន្ធគោលពីរសម្រាប់ aarch64។
