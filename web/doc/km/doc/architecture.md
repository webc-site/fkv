# ស្ថាបត្យកម្ម

## ពេលដំណើរការ

shard នីមួយៗមានខ្សែស្រឡាយ OS ផ្តាច់មុខ និងរយៈពេលដំណើរការ compio ។ សំណើចូលតាមជួរ ingress,
ការចូលរៀនដោយម៉ាស៊ីនរដ្ឋ shard បានបញ្ចប់តាមរយៈបង្កាន់ដៃ oneshot ។

## ការផ្ទុក

ម៉ាស៊ីនប្រើច្បាប់ចម្លងលើការសរសេរ B + មែកធាង។ ទំព័រទិន្នន័យ ទំព័រលិបិក្រម ខ្សែសង្វាក់លើស និង
Manifest ត្រូវ​បាន​តម្រៀប​ជា​ឯកសារ​ជា​ផ្នែក។ សាខាត្រូវបានកំណត់អត្តសញ្ញាណដោយ `(branch, term)` ហើយត្រូវបានកាន់កាប់ដោយនីមួយៗ
រូបថតបង្ហាញ និងគូសផែនទី។

## IO

`fkv_io` កំណត់លក្ខណៈ IO អសមកាល។ `fkv_io_compio`បាន​អនុវត្ត​ជាមួយ compio + io_uring,
`fkv_io_mem` / `fkv_io_sim` ផ្ដល់​ការ​ចងចាំ និង​ការ​ចាក់​បញ្ចូល​ខាង​ក្រោយ​កំហុស `fkv_object_s3` ផ្ដល់
ផ្នែកខាងក្រោយវត្ថុ S3 ។

## ការតស៊ូ

Manifest កត់ត្រាទំព័រឫស ឫស TTL ទិន្នន័យមេតាសាខា និងការគូសផែនទី។ នៅពេលបើកឡើងវិញ
ដំបូង​ចាក់​មេនីហ្វេស​ឡើងវិញ បន្ទាប់​មក​បង្កើត​កម្មវិធី​គូស​ទំព័រ​ឡើង​វិញ ហើយ​បន្ទាប់​មក​ចាប់​ផ្តើម​បម្រើ​សំណើ។
