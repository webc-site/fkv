# fkv

fkv er hrein Rust embed in KV geymsluvél.

## einkennandi

- Einn stýrikerfisþráður á hvern brot, samvinnuvinnulykkja.
- KÚ B+tré, hluti IO sem eingöngu er viðauki.
- page/index/manifest/overflow/compression snið.
- staðbundið/minni/hermt/S3 hlutar bakenda.
- sjálfstæður / ský / biðstöðu eftirlíkingarhamur.
- Engin C ABI, engin Python SDK; aðeins Rust er almenningsviðmótið.
