# fkv

एफकेवी एक शुद्ध रस्ट एंबेडेड केवी स्टोरेज इंजन है।

## विशेषता

- प्रति शार्ड एक ओएस थ्रेड, सहकारी कार्य लूप।
- गाय बी+वृक्ष, केवल परिशिष्ट खंड आईओ।
- पृष्ठ/सूचकांक/प्रकट/अतिप्रवाह/संपीड़न प्रारूप।
- स्थानीय/मेमोरी/सिम्युलेटेड/S3 ऑब्जेक्ट बैकएंड।
- स्टैंडअलोन/क्लाउड/स्टैंडबाय प्रतिकृति मोड।
- कोई सी एबीआई नहीं, कोई पायथन एसडीके नहीं; केवल रस्ट ही सार्वजनिक इंटरफ़ेस है।
