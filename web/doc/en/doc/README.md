# fkv performance

Per-commit performance curves for the Rust port of eloqstore, plus relative
ratios against the C++ oracle.

- `web/public/perf.json`: performance history, updated by `perf.yml`.
- `src/App.svelte`: dashboard.
- `src/styl/`: reused webc reset / form / button / card / kv styles.
- `sh/tran.js`: reused webc translation flow, configured by `tran.yml`.
