# fkv

fkv הוא מנוע אחסון KV משובץ Rust טהור.

## מְאַפיֵן

- חוט מערכת הפעלה אחד לכל רסיס, לולאת עבודה שיתופית.
- COW B+עץ, קטע IO להוספה בלבד.
- פורמט עמוד/אינדקס/מניפסט/הצפה/דחיסה.
- קצה אחורי של אובייקט מקומי/זיכרון/סימולציה/S3.
- מצב העתק עצמאי / ענן / המתנה.
- ללא C ABI, ללא Python SDK; רק Rust הוא הממשק הציבורי.
