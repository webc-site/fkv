# పనితీరు

`fkv_bench` స్థిర కీ స్థలంలో లోడ్‌లను పరీక్షించండి, చదవండి మరియు స్కాన్ చేయండి.

```bash
cargo run --release -p fkv_bench -- \
  --workload write-read --rows 20000 --batch-size 100
```

సూచికలలో నిర్గమాంశ, ప్రతి దశలో జాప్యం మరియు గరిష్ట RSS ఉన్నాయి. విడుదల వర్క్‌ఫ్లో విడుదల x86_64 /
aarch64 కోసం `fkv_bench` బైనరీ.
