# fkv

fkv అనేది స్వచ్ఛమైన రస్ట్ ఎంబెడెడ్ KV నిల్వ ఇంజిన్.

## లక్షణం

- ఒక్కో ముక్కకు ఒక OS థ్రెడ్, సహకార పని లూప్.
- COW B+చెట్టు, అనుబంధం-మాత్రమే సెగ్మెంట్ IO.
- పేజీ/సూచిక/మానిఫెస్ట్/ఓవర్‌ఫ్లో/కంప్రెషన్ ఫార్మాట్.
- స్థానిక/మెమరీ/అనుకరణ/S3 ఆబ్జెక్ట్ బ్యాకెండ్.
- స్వతంత్ర / క్లౌడ్ / స్టాండ్‌బై రెప్లికా మోడ్.
- C ABI లేదు, పైథాన్ SDK లేదు; రస్ట్ మాత్రమే పబ్లిక్ ఇంటర్‌ఫేస్.
