# fkv

fkv এটা বিশুদ্ধ Rust এম্বেডেড KV সংৰক্ষণ ইঞ্জিন।

## বৈশিষ্ট্য

- প্ৰতিটো শ্বাৰ্ডত এটা অ’ এছ থ্ৰেড, সমবায় কাম লুপ।
- COW B+tree, কেৱল এপেণ্ড-অনলি ছেগমেণ্ট IO।
- page/index/manifest/overflow/compression বিন্যাস।
- স্থানীয়/মেমৰি/চিমুলেটেড/S3 বস্তুৰ বেকএণ্ড।
- স্বতন্ত্ৰ / ক্লাউড / ষ্টেণ্ডবাই প্ৰতিলিপি ধৰণ।
- কোনো C ABI নাই, কোনো পাইথন SDK নাই; কেৱল Rust হৈছে ৰাজহুৱা আন্তঃপৃষ্ঠ।
