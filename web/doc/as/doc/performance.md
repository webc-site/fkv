# কাৰ্যক্ষমতা

`fkv_bench` এটা নিৰ্দিষ্ট চাবি স্থানত লিখা, পঢ়া, আৰু স্কেন লোডসমূহ পৰীক্ষা কৰক।

```bash
cargo run --release -p fkv_bench -- \
  --workload write-read --rows 20000 --batch-size 100
```

সূচকসমূহৰ ভিতৰত থ্ৰুপুট, প্ৰতিটো পৰ্যায়ত বিলম্ব, আৰু শীৰ্ষ RSS অন্তৰ্ভুক্ত। মুক্তি কাৰ্য্যপ্ৰবাহ মুক্তি x86_64 /
`fkv_bench` aarch64 ৰ বাবে বাইনাৰী।
