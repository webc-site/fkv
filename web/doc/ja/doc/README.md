# fkv

fkv は純粋な Rust 組み込み KV ストレージ エンジンです。

## 特性

- シャードごとに 1 つの OS スレッド、協調的なワーク ループ。
- COW B+ツリー、追加専用セグメントIO。
- ページ/インデックス/マニフェスト/オーバーフロー/圧縮形式。
- ローカル/メモリ/シミュレート/S3 オブジェクト バックエンド。
- スタンドアロン/クラウド/スタンバイ レプリカ モード。
- C ABI も Python SDK もありません。 Rust だけがパブリックインターフェイスです。
