# 建築

## ランタイム

各シャードには、専用の OS スレッドと compio ランタイムがあります。リクエストは入力キューを介して入ります。
シャード ステート マシンによる承認は、ワンショットの受信によって完了します。

## ストレージ

このエンジンはコピーオンライト B+tree を使用します。データ ページ、インデックス ページ、オーバーフロー チェーン、および
マニフェストはセグメント ファイルにシリアル化されます。ブランチは`(branch, term)`で識別され、それぞれが保持します。
マニフェストとマッピングのスナップショット。

## IO

`fkv_io` 非同期 IO 特性を定義します。 `fkv_io_compio` compio + io_uring で実装されます。
`fkv_io_mem` / `fkv_io_sim` はメモリとフォールト挿入バックエンドを提供し、`fkv_object_s3` は提供します
S3 オブジェクト バックエンド。

## 持続性

マニフェストには、ルート ページ、TTL ルート、ブランチ メタデータ、およびマッピングが記録されます。再開時
まずマニフェストを再生し、次にページ マッパーを再構築して、リクエストの処理を開始します。
