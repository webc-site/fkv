# ವಾಸ್ತುಶಿಲ್ಪ

## ರನ್ಟೈಮ್

ಪ್ರತಿಯೊಂದು ಚೂರುಗಳು ವಿಶೇಷವಾದ OS ಥ್ರೆಡ್ ಮತ್ತು ಕಾಂಪಿಯೊ ರನ್ಟೈಮ್ ಅನ್ನು ಹೊಂದಿದೆ. ವಿನಂತಿಯು ಪ್ರವೇಶ ಸರದಿಯ ಮೂಲಕ ಪ್ರವೇಶಿಸುತ್ತದೆ,
ಶಾರ್ಡ್ ಸ್ಟೇಟ್ ಮೆಷಿನ್ ಮೂಲಕ ಪ್ರವೇಶ, ಒನ್‌ಶಾಟ್ ರಶೀದಿಯ ಮೂಲಕ ಪೂರ್ಣಗೊಂಡಿದೆ.

## ಸಂಗ್ರಹಣೆ

ಎಂಜಿನ್ ಕಾಪಿ-ಆನ್-ರೈಟ್ ಬಿ+ಟ್ರೀ ಅನ್ನು ಬಳಸುತ್ತದೆ. ಡೇಟಾ ಪುಟ, ಸೂಚ್ಯಂಕ ಪುಟ, ಓವರ್‌ಫ್ಲೋ ಚೈನ್ ಮತ್ತು
ಮ್ಯಾನಿಫೆಸ್ಟ್ ಅನ್ನು ಸೆಗ್ಮೆಂಟ್ ಫೈಲ್‌ಗಳಾಗಿ ಧಾರಾವಾಹಿ ಮಾಡಲಾಗಿದೆ. ಶಾಖೆಯನ್ನು `(branch, term)` ಗುರುತಿಸಲಾಗಿದೆ ಮತ್ತು ಪ್ರತಿಯೊಂದೂ ಹಿಡಿದಿಟ್ಟುಕೊಳ್ಳುತ್ತದೆ
ಮ್ಯಾನಿಫೆಸ್ಟ್ ಮತ್ತು ಮ್ಯಾಪಿಂಗ್ ಸ್ನ್ಯಾಪ್‌ಶಾಟ್.

## IO

`fkv_io` ಅಸಮಕಾಲಿಕ IO ಲಕ್ಷಣವನ್ನು ವಿವರಿಸುತ್ತದೆ. `fkv_io_compio` compio + io_uring ನೊಂದಿಗೆ ಅಳವಡಿಸಲಾಗಿದೆ,
`fkv_io_mem` / `fkv_io_sim` ಮೆಮೊರಿ ಮತ್ತು ದೋಷ ಇಂಜೆಕ್ಷನ್ ಬ್ಯಾಕೆಂಡ್‌ಗಳನ್ನು ಒದಗಿಸುತ್ತದೆ, `fkv_object_s3` ಒದಗಿಸುತ್ತದೆ
S3 ಆಬ್ಜೆಕ್ಟ್ ಬ್ಯಾಕೆಂಡ್.

## ಹಠ

ಮ್ಯಾನಿಫೆಸ್ಟ್ ರೂಟ್ ಪೇಜ್, ಟಿಟಿಎಲ್ ರೂಟ್, ಬ್ರಾಂಚ್ ಮೆಟಾಡೇಟಾ ಮತ್ತು ಮ್ಯಾಪಿಂಗ್ ಅನ್ನು ದಾಖಲಿಸುತ್ತದೆ. ಪುನಃ ತೆರೆದಾಗ
ಮೊದಲು ಮ್ಯಾನಿಫೆಸ್ಟ್ ಅನ್ನು ರಿಪ್ಲೇ ಮಾಡಿ, ನಂತರ ಪುಟ ಮ್ಯಾಪರ್ ಅನ್ನು ಮರುನಿರ್ಮಾಣ ಮಾಡಿ, ತದನಂತರ ವಿನಂತಿಗಳನ್ನು ನೀಡಲು ಪ್ರಾರಂಭಿಸಿ.
