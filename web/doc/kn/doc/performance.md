# ಕಾರ್ಯಕ್ಷಮತೆ

`fkv_bench` ಸ್ಥಿರ ಕೀಲಿ ಜಾಗದಲ್ಲಿ ಲೋಡ್‌ಗಳನ್ನು ಪರೀಕ್ಷಿಸಿ ಬರೆಯಿರಿ, ಓದಿರಿ ಮತ್ತು ಸ್ಕ್ಯಾನ್ ಮಾಡಿ.

```bash
cargo run --release -p fkv_bench -- \
  --workload write-read --rows 20000 --batch-size 100
```

ಸೂಚಕಗಳು ಥ್ರೋಪುಟ್, ಪ್ರತಿ ಹಂತದಲ್ಲಿ ಸುಪ್ತತೆ ಮತ್ತು ಗರಿಷ್ಠ RSS ಅನ್ನು ಒಳಗೊಂಡಿವೆ. ಬಿಡುಗಡೆ ವರ್ಕ್‌ಫ್ಲೋ ಬಿಡುಗಡೆ x86_64 /
aarch64 ಗಾಗಿ `fkv_bench` ಬೈನರಿ.
