# fkv

fkv ಶುದ್ಧ ರಸ್ಟ್ ಎಂಬೆಡೆಡ್ KV ಶೇಖರಣಾ ಎಂಜಿನ್ ಆಗಿದೆ.

## ವಿಶಿಷ್ಟ

- ಪ್ರತಿ ಶಾರ್ಡ್‌ಗೆ ಒಂದು ಓಎಸ್ ಥ್ರೆಡ್, ಸಹಕಾರಿ ಕೆಲಸದ ಲೂಪ್.
- COW B+tree, ಅನುಬಂಧ-ಮಾತ್ರ ವಿಭಾಗ IO.
- ಪುಟ/ಸೂಚ್ಯಂಕ/ಮ್ಯಾನಿಫೆಸ್ಟ್/ಓವರ್‌ಫ್ಲೋ/ಸಂಕುಚನ ಸ್ವರೂಪ.
- ಸ್ಥಳೀಯ/ಮೆಮೊರಿ/ಸಿಮ್ಯುಲೇಟೆಡ್/S3 ಆಬ್ಜೆಕ್ಟ್ ಬ್ಯಾಕೆಂಡ್.
- ಸ್ವತಂತ್ರ / ಕ್ಲೌಡ್ / ಸ್ಟ್ಯಾಂಡ್‌ಬೈ ಪ್ರತಿಕೃತಿ ಮೋಡ್.
- C ABI ಇಲ್ಲ, ಪೈಥಾನ್ SDK ಇಲ್ಲ; ರಸ್ಟ್ ಮಾತ್ರ ಸಾರ್ವಜನಿಕ ಇಂಟರ್ಫೇಸ್ ಆಗಿದೆ.
