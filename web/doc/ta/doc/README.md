# fkv

fkv என்பது ஒரு தூய ரஸ்ட் உட்பொதிக்கப்பட்ட KV சேமிப்பு இயந்திரமாகும்.

## பண்பு

- ஒரு ஷார்டுக்கு ஒரு OS நூல், கூட்டுறவு வேலை வளையம்.
- COW B+tree, பிற்சேர்க்கை மட்டும் பிரிவு IO.
- பக்கம்/இன்டெக்ஸ்/மேனிஃபெஸ்ட்/ஓவர்ஃப்ளோ/கம்ப்ரஷன் வடிவம்.
- உள்ளூர்/நினைவக/உருவகப்படுத்தப்பட்ட/S3 பொருள் பின்தளத்தில்.
- தனி / கிளவுட் / காத்திருப்பு பிரதி முறை.
- சி ஏபிஐ இல்லை, பைதான் எஸ்டிகே இல்லை; ரஸ்ட் மட்டுமே பொது இடைமுகம்.
