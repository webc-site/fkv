# စွမ်းဆောင်ရည်

`fkv_bench` ပုံသေသော့နေရာလွတ်တစ်ခုပေါ်တွင် ဖိုင်များကို ရေးခြင်း၊ ဖတ်ခြင်းနှင့် စကင်န်ဖတ်ခြင်းတို့ကို စမ်းသပ်ပါ။

```bash
cargo run --release -p fkv_bench -- \
  --workload write-read --rows 20000 --batch-size 100
```

အညွှန်းကိန်းများသည် အဆင့်တစ်ခုစီတွင် ဖြတ်သန်းမှု၊ တုံ့ပြန်မှု၊ နှင့် RSS အမြင့်ဆုံးဖြစ်သည်။ အလုပ်အသွားအလာ ထုတ်ဝေမှု x86_64 /
`fkv_bench` aarch64 အတွက် ဒွိစုံ။
