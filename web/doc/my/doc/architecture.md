# ဗိသုကာပညာ

## runtime

shard တစ်ခုစီတွင် သီးသန့် OS thread နှင့် compio runtime ရှိသည်။ တောင်းဆိုချက်သည် ingress တန်းစီခြင်းမှတဆင့် ဝင်လာသည်၊
shard state စက်ဖြင့် ဝင်ခွင့်၊ oneshot လက်ခံဖြတ်ပိုင်းဖြင့် ပြီးသွားသည်။

## သိုလှောင်မှု

အင်ဂျင်သည် copy-on-write B+tree ကိုအသုံးပြုသည်။ ဒေတာစာမျက်နှာ၊ အညွှန်းစာမျက်နှာ၊ လွှမ်းခြုံကွင်းဆက်နှင့်
မန်နီးဖက်စ်ကို အပိုင်းဖိုင်များအဖြစ် စီစဥ်ထားသည်။ ဌာနခွဲကို `(branch, term)`ဖြင့် ခွဲခြားသတ်မှတ်ထားပြီး တစ်ခုစီမှ ချုပ်ကိုင်ထားသည်။
သရုပ်ဖော်ခြင်းနှင့် မြေပုံဆွဲခြင်း လျှပ်တစ်ပြက်။

## IO

`fkv_io`သည် အညီအမျှ IO လက္ခဏာကို သတ်မှတ်သည်။ `fkv_io_compio` compio + io_uring ဖြင့် အကောင်အထည်ဖော်သည်၊
`fkv_io_mem` / `fkv_io_sim` မှတ်ဉာဏ်နှင့် အမှားအယွင်းများကို ပံ့ပိုးပေးသည်၊ `fkv_object_s3` ပံ့ပိုးပေးသည်
S3 အရာဝတ္ထုနောက်ခံ။

## စွဲမြဲစွာ၊

မန်နီးဖက်စ်သည် အမြစ်စာမျက်နှာ၊ TTL အမြစ်၊ ဌာနခွဲ မက်တာဒေတာနှင့် မြေပုံဆွဲခြင်းကို မှတ်တမ်းတင်သည်။ ပြန်ဖွင့်ချိန်
ပထမဦးစွာ မန်နီးဖက်စ်ကို ပြန်ဖွင့်ပါ၊ ထို့နောက် စာမျက်နှာမြေပုံကို ပြန်လည်တည်ဆောက်ပါ၊ ထို့နောက် တောင်းဆိုချက်များကို စတင်ဆောင်ရွက်ပါ။
