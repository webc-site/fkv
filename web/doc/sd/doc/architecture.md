# آرڪيٽيڪچر

## هلندڙ وقت

هر شارڊ ۾ هڪ خاص OS ٿريڊ ۽ هڪ ڪمپيو رن ٽائم آهي. درخواست داخل ٿيڻ واري قطار ذريعي داخل ٿئي ٿي،
شارڊ اسٽيٽ مشين ذريعي داخلا، هڪ شاٽ رسيد ذريعي مڪمل.

## ذخيرو

انجڻ استعمال ڪري ٿو ڪاپي-آن-لکڻ B + وڻ. ڊيٽا پيج، انڊيڪس پيج، اوور فلو چين ۽
منشور کي سيگمينٽ فائلن ۾ سيريل ڪيو ويو آھي. شاخ جي سڃاڻپ ڪئي وئي آهي `(branch, term)` ۽ هر هڪ طرفان منعقد ڪئي وئي آهي
ظاهر ۽ نقشي جي تصوير.

## IO

`fkv_io` وضاحت ڪري ٿو غير مطابقت واري IO خاصيت. `fkv_io_compio` compio + io_uring سان لاڳو،
`fkv_io_mem` / `fkv_io_sim` مهيا ڪري ٿي ميموري ۽ فالٽ انجيڪشن پٺاڻ، `fkv_object_s3` مهيا ڪري ٿي
S3 اعتراض پس منظر.

## استقامت

ظاهري رڪارڊ روٽ پيج، TTL روٽ، برانچ ميٽاداٽا ۽ ميپنگ. جڏهن ٻيهر کوليو
پهرين منشور کي ٻيهر هلايو، پوءِ صفحي جي ميپر کي ٻيهر ٺاهيو، ۽ پوءِ درخواستون پيش ڪرڻ شروع ڪريو.
