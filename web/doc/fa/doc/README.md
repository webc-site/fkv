# fkv

fkv یک موتور ذخیره سازی KV جاسازی شده Rust خالص است.

## مشخصه

- یک رشته سیستم عامل در هر خرده، حلقه کار تعاونی.
- COW B+tree، بخش IO فقط ضمیمه.
- صفحه/ایندکس/مانیفست/سرریز/فرمت فشرده سازی.
- باطن شیء محلی/حافظه/شبیه سازی شده/S3.
- حالت ماکت مستقل / ابری / آماده به کار.
- بدون C ABI، بدون Python SDK. فقط Rust رابط عمومی است.
