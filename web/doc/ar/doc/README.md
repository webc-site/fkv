# fkv

fkv هو محرك تخزين KV مدمج في Rust.

## مميزة

- مؤشر ترابط نظام تشغيل واحد لكل حلقة عمل تعاونية.
- COW B+شجرة، قطعة الإلحاق IO فقط.
- الصفحة/الفهرس/البيان/التجاوز/تنسيق الضغط.
- الواجهة الخلفية لكائن محلي/ذاكرة/محاكاة/S3.
- وضع النسخ المتماثل المستقل / السحابي / الاستعداد.
- لا يوجد C ABI، ولا يوجد Python SDK؛ الصدأ فقط هو الواجهة العامة.
