# fkv

fkv — это механизм хранения KV, встроенный в чистый Rust.

## характеристика

- Один поток ОС на каждый сегмент, совместный рабочий цикл.
- COW B+tree, сегмент ввода-вывода только для добавления.
- формат страницы/индекса/манифеста/переполнения/сжатия.
- серверная часть объекта local/memory/simulated/S3.
- режим автономной/облачной/резервной реплики.
- Нет C ABI, нет Python SDK; только Rust является общедоступным интерфейсом.
