# Архитектура

## время выполнения

Каждый шард имеет эксклюзивный поток ОС и среду выполнения Compio. Запрос поступает через входную очередь,
Прием через государственный автомат сегмента осуществляется посредством одноразовой квитанции.

## хранилище

Движок использует B+дерево копирования при записи. страница данных, индексная страница, цепочка переполнения и
Манифест сериализуется в файлы сегментов. ветвь идентифицируется `(branch, term)` и принадлежит каждому
снимок манифеста и сопоставления.

## IO

`fkv_io` Определяет особенность асинхронного ввода-вывода. `fkv_io_compio` Реализовано с помощью compio + io_uring,
`fkv_io_mem` / `fkv_io_sim` предоставляет механизмы памяти и внедрения ошибок, `fkv_object_s3` обеспечивает
Серверная часть объекта S3.

## упорство

Манифест записывает корневую страницу, корень TTL, метаданные ветки и сопоставление. Когда снова откроется
Сначала воспроизведите манифест, затем перестройте преобразователь страниц, а затем начните обслуживать запросы.
