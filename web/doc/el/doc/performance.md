# Απόδοση

`fkv_bench` Δοκιμάστε την εγγραφή, την ανάγνωση και τη σάρωση φορτίων σε ένα σταθερό χώρο κλειδιού.

```bash
cargo run --release -p fkv_bench -- \
  --workload write-read --rows 20000 --batch-size 100
```

Οι δείκτες περιλαμβάνουν τη διεκπεραίωση, την καθυστέρηση σε κάθε στάδιο και το μέγιστο RSS. απελευθέρωση ροής εργασίας απελευθέρωση x86_64 /
`fkv_bench` δυαδικό για aarch64.
