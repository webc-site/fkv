# fkv

Το fkv είναι ένας καθαρός κινητήρας αποθήκευσης KV με ενσωματωμένη Rust.

## χαρακτηριστικός

- Ένα νήμα λειτουργικού συστήματος ανά θραύσμα, βρόχος συνεργασίας.
- COW B+tree, τμήμα IO μόνο για προσθήκη.
- σελίδα/ευρετήριο/προφανή/υπερχείλιση/μορφή συμπίεσης.
- τοπικό/μνήμη/προσομοίωση/υποστήριξη αντικειμένου S3.
- Αυτόνομη / σύννεφο / λειτουργία αναμονής αντίγραφο.
- Χωρίς C ABI, χωρίς Python SDK. μόνο το Rust είναι η δημόσια διεπαφή.
