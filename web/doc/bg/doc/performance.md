# Производителност

`fkv_bench` Тестови зареждания за запис, четене и сканиране на фиксирано пространство за ключове.

```bash
cargo run --release -p fkv_bench -- \
  --workload write-read --rows 20000 --batch-size 100
```

Индикаторите включват пропускателна способност, латентност на всеки етап и пиков RSS. освобождаване на работен процес версия x86_64 /
`fkv_bench` двоичен файл за aarch64.
