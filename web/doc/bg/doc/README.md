# fkv

fkv е чисто вграден KV двигател за съхранение на Rust.

## характеристика

- Една OS нишка на фрагмент, кооперативен работен цикъл.
- COW B+дърво, сегмент само за добавяне IO.
- формат на страница/индекс/манифест/препълване/компресия.
- локален/памет/симулиран/S3 обект бекенд.
- самостоятелен / облачен / режим на реплика в режим на готовност.
- Без C ABI, без Python SDK; само Rust е публичният интерфейс.
