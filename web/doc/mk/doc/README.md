# fkv

fkv е чист мотор за складирање на KV вграден во Rust.

## карактеристика

- Една нишка на ОС по парче, кооперативна работна јамка.
- COW B + дрво, сегмент IO само за додаток.
- страница/индекс/манифест/прелевање/формат на компресија.
- локален/меморија/симулиран/S3 објект заднина.
- самостоен / облак / режим на реплика на подготвеност.
- Нема C ABI, нема Python SDK; само Rust е јавниот интерфејс.
