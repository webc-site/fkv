# Перформанси

`fkv_bench` Тестирајте ги оптоварувањата за пишување, читање и скенирање на фиксен простор за клучеви.

```bash
cargo run --release -p fkv_bench -- \
  --workload write-read --rows 20000 --batch-size 100
```

Индикаторите вклучуваат пропусност, латентност во секоја фаза и врвен RSS. ослободување на работниот тек ослободување x86_64 /
`fkv_bench` бинарен за aarch64.
