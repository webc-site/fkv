# fkv

fkv ni injini ya kuhifadhi ya KV iliyopachikwa Rust.

## tabia

- Uzi mmoja wa Mfumo wa Uendeshaji kwa kila shard, kitanzi cha kazi cha ushirika.
- NG'OMBE B+mti, sehemu ya nyongeza tu IO.
- page/index/manifest/overflow/compression format.
- local/memory/simulated/S3 object backend.
- ilio / hali ya wingu / replica ya kusubiri.
- Hakuna C ABI, hakuna SDK ya Python; Rust pekee ndio kiolesura cha umma.
