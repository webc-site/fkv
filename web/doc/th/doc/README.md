# fkv

fkv คือเอ็นจิ้นการจัดเก็บ KV แบบฝัง Rust ล้วนๆ

## ลักษณะเฉพาะ

- หนึ่งเธรดระบบปฏิบัติการต่อชาร์ด ลูปการทำงานร่วมกัน
- COW B+tree ผนวกเฉพาะส่วน IO
- หน้า/ดัชนี/รายการ/ล้น/รูปแบบการบีบอัด
- แบ็กเอนด์ออบเจ็กต์โลคัล/หน่วยความจำ/จำลอง/S3
- โหมดจำลองแบบสแตนด์อโลน / คลาวด์ / สแตนด์บาย
- ไม่มี C ABI ไม่มี Python SDK เฉพาะ Rust เท่านั้นที่เป็นอินเทอร์เฟซสาธารณะ
