# สถาปัตยกรรม

## รันไทม์

แต่ละชาร์ดมีเธรด OS พิเศษและรันไทม์คอมไพโอ คำขอเข้าสู่คิวทางเข้า
การเข้าชมโดยเครื่องสถานะชาร์ด ดำเนินการผ่านการรับครั้งเดียว

## พื้นที่จัดเก็บ

เอ็นจิ้นใช้การคัดลอกเมื่อเขียน B+tree หน้าข้อมูล หน้าดัชนี ห่วงโซ่ล้น และ
รายการจะถูกทำให้เป็นอนุกรมเป็นไฟล์ส่วน สาขาถูกระบุโดย `(branch, term)` และถือโดยแต่ละสาขา
รายการและภาพรวมการทำแผนที่

## IO

`fkv_io` กำหนดลักษณะ IO แบบอะซิงโครนัส `fkv_io_compio` ใช้กับ compio + io_uring
`fkv_io_mem` / `fkv_io_sim` จัดเตรียมหน่วยความจำและแบ็กเอนด์การฉีดข้อผิดพลาด `fkv_object_s3` จัดเตรียม
แบ็กเอนด์วัตถุ S3

## ความพากเพียร

รายการจะบันทึกหน้ารูท, รูท TTL, ข้อมูลเมตาของสาขา และการแมป เมื่อเปิดใหม่
ขั้นแรกให้เล่นไฟล์ Manifest ซ้ำ จากนั้นสร้างตัวทำแผนที่หน้าใหม่ จากนั้นจึงเริ่มให้บริการคำขอ
