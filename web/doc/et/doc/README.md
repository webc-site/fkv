# fkv

fkv on puhas Rooste sisseehitatud KV salvestusmootor.

## iseloomulik

- Üks OS-i lõim killu kohta, koostöö töösilmus.
- LEHM B+puu, lisab ainult segment IO.
- leht/indeks/manifest/ületäitmine/tihendusvorming.
- kohalik/mälu/simuleeritud/S3 objekti taustaprogramm.
- eraldiseisev / pilve- / ooterežiimi replikarežiim.
- puudub C ABI ega Pythoni SDK; ainult Rust on avalik liides.
