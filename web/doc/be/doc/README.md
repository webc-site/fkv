# fkv

fkv - гэта сістэма захоўвання KV, убудаваная ў чысты Rust.

## характарыстыка

- Адзін паток АС на шард, кааператыўны працоўны цыкл.
- COW B+дрэва, сегмент IO толькі для дадання.
- старонка/індэкс/маніфест/перапаўненне/фармат сціску.
- Бэкэнд лакальнага/памяці/мадэляванага/аб'екта S3.
- аўтаномны / воблачны / рэжым чакання рэплікі.
- Няма C ABI, няма Python SDK; толькі Rust з'яўляецца публічным інтэрфейсам.
