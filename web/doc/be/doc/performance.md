# Прадукцыйнасць

`fkv_bench` Тэставыя загрузкі запісу, чытання і сканавання ў фіксаванай прасторы ключоў.

```bash
cargo run --release -p fkv_bench -- \
  --workload write-read --rows 20000 --batch-size 100
```

Паказчыкі ўключаюць прапускную здольнасць, затрымку на кожным этапе і пік RSS. выпуск працоўнага працэсу выпуск x86_64 /
`fkv_bench` двайковы файл для aarch64.
