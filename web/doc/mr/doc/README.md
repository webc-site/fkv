# fkv

fkv हे शुद्ध रस्ट एम्बेडेड KV स्टोरेज इंजिन आहे.

## वैशिष्ट्यपूर्ण

- एक ओएस थ्रेड प्रति शार्ड, सहकारी कार्य लूप.
- COW B+वृक्ष, केवळ-जोडलेला विभाग IO.
- पृष्ठ/अनुक्रमणिका/मनीफेस्ट/ओव्हरफ्लो/संक्षेप स्वरूप.
- लोकल/मेमरी/सिम्युलेटेड/एस3 ऑब्जेक्ट बॅकएंड.
- स्टँडअलोन / क्लाउड / स्टँडबाय प्रतिकृती मोड.
- C ABI नाही, Python SDK नाही; फक्त गंज सार्वजनिक इंटरफेस आहे.
