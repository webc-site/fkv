# পারফরম্যান্স

`fkv_bench` একটি নির্দিষ্ট কী স্পেসে লোড লিখুন, পড়ুন এবং স্ক্যান করুন।

```bash
cargo run --release -p fkv_bench -- \
  --workload write-read --rows 20000 --batch-size 100
```

সূচকগুলির মধ্যে রয়েছে থ্রুপুট, প্রতিটি পর্যায়ে লেটেন্সি এবং সর্বোচ্চ RSS। রিলিজ ওয়ার্কফ্লো রিলিজ x86_64 /
aarch64 এর জন্য `fkv_bench` বাইনারি।
