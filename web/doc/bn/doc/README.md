# fkv

fkv একটি বিশুদ্ধ মরিচা এমবেডেড কেভি স্টোরেজ ইঞ্জিন।

## বৈশিষ্ট্য

- একটি OS থ্রেড প্রতি শার্ড, সমবায় কাজের লুপ।
- COW B+বৃক্ষ, শুধুমাত্র যোগ করার জন্য সেগমেন্ট IO।
- পৃষ্ঠা/সূচী/মেনিফেস্ট/ওভারফ্লো/সংকোচন বিন্যাস।
- local/memory/simulated/S3 অবজেক্ট ব্যাকএন্ড।
- স্বতন্ত্র/ক্লাউড/স্ট্যান্ডবাই রেপ্লিকা মোড।
- সি এবিআই নেই, পাইথন এসডিকে নেই; শুধুমাত্র মরিচা হল পাবলিক ইন্টারফেস।
