# স্থাপত্য

## রানটাইম

প্রতিটি শার্ডের একটি এক্সক্লুসিভ OS থ্রেড এবং একটি কম্পিও রানটাইম রয়েছে৷ অনুরোধটি প্রবেশ সারির মাধ্যমে প্রবেশ করে,
শার্ড স্টেট মেশিনের মাধ্যমে ভর্তি, একশট রসিদের মাধ্যমে সম্পন্ন।

## স্টোরেজ

ইঞ্জিন কপি-অন-রাইট B+ট্রি ব্যবহার করে। ডেটা পৃষ্ঠা, সূচক পৃষ্ঠা, ওভারফ্লো চেইন এবং
ম্যানিফেস্টটি সেগমেন্ট ফাইলে ক্রমিক করা হয়। শাখা `(branch, term)` দ্বারা চিহ্নিত করা হয় এবং প্রত্যেকের দ্বারা অনুষ্ঠিত হয়
ম্যানিফেস্ট এবং ম্যাপিং স্ন্যাপশট।

## IO

`fkv_io` অ্যাসিঙ্ক্রোনাস IO বৈশিষ্ট্য সংজ্ঞায়িত করে৷ `fkv_io_compio` compio + io_uring এর সাথে বাস্তবায়িত,
`fkv_io_mem` / `fkv_io_sim` মেমরি এবং ফল্ট ইনজেকশন ব্যাকএন্ড প্রদান করে, `fkv_object_s3` প্রদান করে
S3 অবজেক্ট ব্যাকএন্ড।

## অধ্যবসায়

ম্যানিফেস্ট রুট পৃষ্ঠা, TTL রুট, শাখা মেটাডেটা এবং ম্যাপিং রেকর্ড করে। আবার খুললে
প্রথমে ম্যানিফেস্ট রিপ্লে করুন, তারপর পৃষ্ঠা ম্যাপার পুনর্নির্মাণ করুন এবং তারপর অনুরোধ পরিবেশন শুরু করুন।
