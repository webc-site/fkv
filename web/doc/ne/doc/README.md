# fkv

fkv एक शुद्ध रस्ट एम्बेडेड KV भण्डारण इन्जिन हो।

## विशेषता

- एक ओएस थ्रेड प्रति शार्ड, सहकारी कार्य लूप।
- COW B+ रूख, संलग्न-मात्र खण्ड IO।
- पृष्ठ/सूचकांक/म्यानिफेस्ट/ओभरफ्लो/संकुचन ढाँचा।
- local/memory/simulated/S3 वस्तु ब्याकइन्ड।
- स्ट्यान्डअलोन / क्लाउड / स्ट्यान्डबाइ प्रतिकृति मोड।
- कुनै C ABI छैन, पाइथन SDK छैन; केवल रस्ट सार्वजनिक इन्टरफेस हो।
