# କାର୍ଯ୍ୟଦକ୍ଷତା

`fkv_bench` ଏକ ନିର୍ଦ୍ଦିଷ୍ଟ କି ସ୍ଥାନରେ ଲୋଡ୍ ପରୀକ୍ଷା, ପ read, ଏବଂ ସ୍କାନ୍ କର |

```bash
cargo run --release -p fkv_bench -- \
  --workload write-read --rows 20000 --batch-size 100
```

ସୂଚକଗୁଡ଼ିକରେ ଥ୍ରୋପପୁଟ, ପ୍ରତ୍ୟେକ ପର୍ଯ୍ୟାୟରେ ବିଳମ୍ବତା ଏବଂ ଶିଖର RSS ଅନ୍ତର୍ଭୁକ୍ତ | କାର୍ଯ୍ୟ ପ୍ରବାହ ପ୍ରକାଶନ x86_64 /
aarch64 ପାଇଁ `fkv_bench` ବାଇନାରୀ |
