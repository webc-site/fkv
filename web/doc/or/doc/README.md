# fkv

## ବ istic ଶିଷ୍ଟ୍ୟ

- ଶାର୍ଡ ପ୍ରତି ଗୋଟିଏ OS ଥ୍ରେଡ୍, ସହଯୋଗୀ କାର୍ଯ୍ୟ ଲୁପ୍ |
- COW B + ବୃକ୍ଷ, ଆପେଣ୍ଡ-କେବଳ ସେଗମେଣ୍ଟ IO |
- ପୃଷ୍ଠା / ଇଣ୍ଡେକ୍ସ / ମନିଫେଷ୍ଟ୍ / ଓଭରଫ୍ଲୋ / ସଙ୍କୋଚନ ଫର୍ମାଟ୍ |
- ଲୋକାଲ୍ / ମେମୋରୀ / ସିମୁଲେଡ୍ / S3 ଅବଜେକ୍ଟ ବ୍ୟାକେଣ୍ଡ୍ |
- ଷ୍ଟାଣ୍ଡାଲୋନ୍ / କ୍ଲାଉଡ୍ / ଷ୍ଟାଣ୍ଡବାଇ ପ୍ରତିକୃତି ମୋଡ୍ |
- ନା C ABI, ନା Python SDK; କେବଳ ରୁଷ୍ଟ ହେଉଛି ସର୍ବସାଧାରଣ ଇଣ୍ଟରଫେସ୍ |
