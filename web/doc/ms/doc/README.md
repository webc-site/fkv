# fkv

fkv ialah enjin storan KV terbenam Rust tulen.

## ciri

- Satu utas OS setiap serpihan, gelung kerja koperasi.
- Pokok B+LEMBU, tambahkan sahaja segmen IO.
- format halaman/indeks/manifest/limpahan/mampatan.
- bahagian belakang objek tempatan/memori/simulasi/S3.
- mod replika kendiri / awan / siap sedia.
- Tiada C ABI, tiada SDK Python; hanya Rust adalah antara muka awam.
