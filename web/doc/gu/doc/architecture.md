# આર્કિટેક્ચર

## રનટાઇમ

દરેક શાર્ડમાં એક વિશિષ્ટ OS થ્રેડ અને કમ્પિયો રનટાઇમ હોય છે. વિનંતી પ્રવેશ કતાર દ્વારા દાખલ થાય છે,
શાર્ડ સ્ટેટ મશીન દ્વારા પ્રવેશ, વનશોટ રસીદ દ્વારા પૂર્ણ.

## સંગ્રહ

એન્જિન કોપી-ઓન-રાઈટ B+ટ્રીનો ઉપયોગ કરે છે. ડેટા પેજ, ઈન્ડેક્સ પેજ, ઓવરફ્લો ચેઈન અને
મેનિફેસ્ટ સેગમેન્ટ ફાઇલોમાં સીરીયલાઇઝ્ડ છે. શાખા `(branch, term)` દ્વારા ઓળખવામાં આવે છે અને દરેક દ્વારા રાખવામાં આવે છે
મેનિફેસ્ટ અને મેપિંગ સ્નેપશોટ.

## IO

`fkv_io` અસુમેળ IO લક્ષણ વ્યાખ્યાયિત કરે છે. `fkv_io_compio` compio + io_uring સાથે અમલી,
`fkv_io_mem` / `fkv_io_sim` મેમરી અને ફોલ્ટ ઇન્જેક્શન બેકએન્ડ પ્રદાન કરે છે, `fkv_object_s3` પ્રદાન કરે છે
S3 ઑબ્જેક્ટ બેકએન્ડ.

## દ્રઢતા

મેનિફેસ્ટ રૂટ પેજ, TTL રૂટ, શાખા મેટાડેટા અને મેપિંગ રેકોર્ડ કરે છે. જ્યારે ફરીથી ખોલો
પહેલા મેનિફેસ્ટને ફરીથી ચલાવો, પછી પૃષ્ઠ મેપરને ફરીથી બનાવો અને પછી વિનંતીઓ આપવાનું શરૂ કરો.
