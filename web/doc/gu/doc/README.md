# fkv

fkv એ શુદ્ધ રસ્ટ એમ્બેડેડ KV સ્ટોરેજ એન્જિન છે.

## લાક્ષણિકતા

- શાર્ડ દીઠ એક OS થ્રેડ, સહકારી કાર્ય લૂપ.
- COW B+ટ્રી, ફક્ત-એન્ડ-ઓન્લી સેગમેન્ટ IO.
- પૃષ્ઠ/ઇન્ડેક્સ/મેનિફેસ્ટ/ઓવરફ્લો/કમ્પ્રેશન ફોર્મેટ.
- સ્થાનિક/મેમરી/સિમ્યુલેટેડ/એસ3 ઑબ્જેક્ટ બેકએન્ડ.
- એકલ / વાદળ / સ્ટેન્ડબાય પ્રતિકૃતિ મોડ.
- ના C ABI, ના Python SDK; માત્ર રસ્ટ જાહેર ઇન્ટરફેસ છે.
