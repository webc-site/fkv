# fkv

fkv ایک خالص مورچا ایمبیڈڈ KV اسٹوریج انجن ہے۔

## خصوصیت

- ایک OS تھریڈ فی شارڈ، کوآپریٹو ورک لوپ۔
- COW B+Tree، صرف اپنڈ سیگمنٹ IO۔
- صفحہ/انڈیکس/مینی فیسٹ/اوور فلو/کمپریشن فارمیٹ۔
- local/memory/simulated/S3 آبجیکٹ پسدید۔
- اسٹینڈ اسٹون / کلاؤڈ / اسٹینڈ بائی ریپلیکا موڈ۔
- کوئی C ABI، کوئی Python SDK نہیں؛ صرف زنگ عوامی انٹرفیس ہے.
