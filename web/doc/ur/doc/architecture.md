# فن تعمیر

## رن ٹائم

ہر شارڈ میں ایک خصوصی OS تھریڈ اور ایک کمپیو رن ٹائم ہوتا ہے۔ درخواست داخلے کی قطار میں داخل ہوتی ہے،
شارڈ سٹیٹ مشین کے ذریعے داخلہ، ایک شاٹ رسید کے ذریعے مکمل۔

## ذخیرہ

انجن کاپی آن رائٹ B+ٹری استعمال کرتا ہے۔ ڈیٹا پیج، انڈیکس پیج، اوور فلو چین اور
مینی فیسٹ کو سیگمنٹ فائلوں میں سیریلائز کیا جاتا ہے۔ برانچ کی شناخت `(branch, term)` سے ہوتی ہے اور ہر ایک کے پاس ہوتا ہے۔
مینی فیسٹ اور میپنگ سنیپ شاٹ۔

## IO

`fkv_io` غیر مطابقت پذیر IO خصوصیت کی وضاحت کرتا ہے۔ `fkv_io_compio` compio + io_uring کے ساتھ لاگو کیا گیا،
`fkv_io_mem` / `fkv_io_sim` میموری اور فالٹ انجیکشن بیک اینڈ فراہم کرتا ہے، `fkv_object_s3` فراہم کرتا ہے
S3 آبجیکٹ پسدید۔

## استقامت

مینی فیسٹ روٹ پیج، TTL روٹ، برانچ میٹا ڈیٹا اور میپنگ کو ریکارڈ کرتا ہے۔ جب دوبارہ کھولیں۔
پہلے مینی فیسٹ کو دوبارہ چلائیں، پھر صفحہ میپر کو دوبارہ بنائیں، اور پھر درخواستیں پیش کرنا شروع کریں۔
