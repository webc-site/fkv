# 건축학

## 실행 시간

각 샤드에는 전용 OS 스레드와 compio 런타임이 있습니다. 요청은 수신 대기열을 통해 들어갑니다.
샤드 상태 머신으로 입장, 원샷 영수증을 통해 완료됩니다.

## 저장

엔진은 쓰기 중 복사 B+트리를 사용합니다. 데이터 페이지, 인덱스 페이지, 오버플로 체인 및
매니페스트는 세그먼트 파일로 직렬화됩니다. 지점은 `(branch, term)`로 식별되며 각 지점이 보유합니다.
매니페스트 및 매핑 스냅샷.

## IO

`fkv_io` 비동기 IO 특성을 정의합니다. `fkv_io_compio` compio + io_uring으로 구현,
`fkv_io_mem` / `fkv_io_sim`는 메모리 및 오류 주입 백엔드를 제공하고, `fkv_object_s3`은
S3 객체 백엔드.

## 고집

매니페스트는 루트 페이지, TTL 루트, 분기 메타데이터 및 매핑을 기록합니다. 다시 열 때
먼저 매니페스트를 재생한 다음 페이지 매퍼를 다시 빌드하고 요청 처리를 시작합니다.
