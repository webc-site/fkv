# fkv

фкв је чист Руст уграђен КВ механизам за складиштење.

## карактеристичан

- Једна ОС нит по фрагменту, кооперативна радна петља.
- ЦОВ Б+стабло, сегмент ИО само за додавање.
- страница/индекс/манифест/преливање/формат компресије.
- локални/мемори/симулирани/С3 објекат бацкенд.
- самостални / облак / режим приправности реплика.
- Нема Ц АБИ, нема Питхон СДК; само Руст је јавни интерфејс.
