# fkv

fkv - таза Rust енгізілген КВ сақтау қозғалтқышы.

## ерекшелік

- Әр үзіндіге бір OS ағыны, бірлескен жұмыс циклі.
- COW B+ағаш, тек IO сегментін қосу.
- бет/индекс/манифест/толып кету/қысу пішімі.
- жергілікті/жад/имитациялық/S3 нысан сервері.
- автономды / бұлтты / күту реплика режимі.
- No C ABI, no Python SDK; тек Rust жалпыға ортақ интерфейс.
