# fkv

fkv — це чистий вбудований механізм KV, вбудований у Rust.

## характеристика

- Один потік ОС на сегмент, спільний робочий цикл.
- COW B+дерево, сегмент IO лише для додавання.
- сторінка/індекс/маніфест/переповнення/формат стиснення.
- сервер локальної/пам'яті/модельованого/об'єкта S3.
- автономний / хмарний / резервний режим репліки.
- Немає C ABI, немає Python SDK; тільки Rust є публічним інтерфейсом.
