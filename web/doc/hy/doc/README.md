# fkv

fkv-ն մաքուր Rust ներդրված KV պահեստավորման շարժիչ է:

## բնորոշիչ

- Մեկ OS շարանը յուրաքանչյուր բեկորի համար, համագործակցային աշխատանքային հանգույց:
- COW B+tree, հավելված միայն հատված IO:
- էջ / ինդեքս / մանիֆեստ / գերհոսք / սեղմման ձևաչափ:
- տեղական/հիշողություն/սիմուլյացված/S3 օբյեկտի հետնամաս:
- ինքնուրույն / ամպ / սպասման կրկնօրինակի ռեժիմ:
- Ոչ C ABI, ոչ Python SDK; միայն Rust-ը հանրային ինտերֆեյսն է:
