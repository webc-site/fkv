# Արտադրողականություն

`fkv_bench` Ստուգեք գրելու, կարդալու և սկանավորելու բեռները ֆիքսված ստեղնաշարի վրա:

```bash
cargo run --release -p fkv_bench -- \
  --workload write-read --rows 20000 --batch-size 100
```

Ցուցանիշները ներառում են թողունակությունը, ուշացումը յուրաքանչյուր փուլում և առավելագույն RSS: աշխատանքի հոսքի թողարկում x86_64 /
