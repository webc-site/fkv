# Ճարտարապետություն

## գործարկման ժամանակը

Յուրաքանչյուր բեկոր ունի OS-ի բացառիկ թեմա և կոմպոյի գործարկման ժամանակ: Հարցումը մուտքագրվում է մուտքի հերթով,
Ընդունելությունը բեկորային պետական ​​մեքենայով, լրացվում է oneshot անդորրագրի միջոցով։

## պահեստավորում

Շարժիչը օգտագործում է «copy-on-write» B+tree: տվյալների էջ, ինդեքսային էջ, վարարման շղթա և
Մանիֆեստը սերիականացված է սեգմենտային ֆայլերի: մասնաճյուղը նույնականացվում է `(branch, term)`-ով և պահվում է յուրաքանչյուրի կողմից
