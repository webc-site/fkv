# არქიტექტურა

## გაშვების დრო

თითოეულ ფრაგმენტს აქვს ექსკლუზიური OS თემა და კომპიო გაშვების დრო. მოთხოვნა შემოდის შესვლის რიგში,
დაშვება ნატეხი სახელმწიფო მანქანით, დასრულებულია ერთჯერადი ქვითრით.

## შენახვა

ძრავა იყენებს ასლი-ჩაწერის B+tree-ს. მონაცემთა გვერდი, ინდექსის გვერდი, გადინება ჯაჭვი და
manifest არის სერიული სეგმენტის ფაილებად. ფილიალი იდენტიფიცირებულია `(branch, term)`-ით და იმართება თითოეულის მიერ
მანიფესტი და რუკების სნეპშოტი.

## IO

`fkv_io` განსაზღვრავს ასინქრონულ IO მახასიათებელს. `fkv_io_compio` განხორციელდა compio + io_uring-ით,
`fkv_io_mem` / `fkv_io_sim` უზრუნველყოფს მეხსიერების და შეცდომის ინექციის უკანა ნაწილებს, `fkv_object_s3` უზრუნველყოფს
S3 ობიექტის უკანა ნაწილი.

## გამძლეობა

მანიფესტი იწერს root გვერდს, TTL root-ს, ფილიალის მეტამონაცემებს და რუკებს. როდესაც ხელახლა გახსნა
ჯერ ხელახლა გაიმეორეთ მანიფესტი, შემდეგ აღადგინეთ გვერდის მაპერი და შემდეგ დაიწყეთ მოთხოვნების სერვისი.
