# fkv

fkv არის სუფთა Rust-ის ჩაშენებული KV შესანახი ძრავა.

## დამახასიათებელი

- ერთი OS ძაფი თითო ნაჭერზე, ერთობლივი სამუშაო ციკლი.
- COW B+ხე, მხოლოდ დამატებული სეგმენტი IO.
- გვერდი/ინდექსი/მანიფესტი/გადინება/შეკუმშვის ფორმატი.
- ლოკალური/მეხსიერების/სიმულირებული/S3 ობიექტის უკანა ნაწილი.
- დამოუკიდებელი / ღრუბელი / ლოდინის რეპლიკა რეჟიმი.
- არ არის C ABI, არ არის Python SDK; მხოლოდ Rust არის საჯარო ინტერფეისი.
