# წარმადობა

`fkv_bench` ჩაწერის, წაკითხვისა და სკანირების ტესტირება გასაღების ფიქსირებულ სივრცეზე.

```bash
cargo run --release -p fkv_bench -- \
  --workload write-read --rows 20000 --batch-size 100
```

ინდიკატორები მოიცავს გამტარუნარიანობას, შეყოვნებას თითოეულ ეტაპზე და პიკს RSS. სამუშაო ნაკადის გამოშვება x86_64 /
`fkv_bench` ბინარული aarch64-ისთვის.
